DEMO SCREENS - Sample details lang. Walang audio o totoong transaksyon.

1. Gumawa ng account
Buksan ang dashboard.paymongo.com/signup. Ilagay ang email na ginagamit mo at gumawa ng password. Basahin at tanggapin ang Terms at Privacy Policy. Optional ang referral code.

2. I-verify ang email
Buksan ang email mula sa PayMongo. Ilagay ang 6-digit code na ipinadala nila. Sample code lang ang nasa demo na ito.

3. I-verify ang pagkakakilanlan
Sundin ang camera check at pagkuha ng larawan ng valid ID. Ilagay ang personal details na tugma sa ID mo. Sa tunay na website lang gawin ito.

4. Kumpletuhin ang negosyo
Para sa mga serbisyong kailangan ng business verification, sagutan ang detalye ng shop. Ihanda ang registration, TIN at address. Sundin ang requirements ng PayMongo bago gumamit ng totoong bayad.

5. Hanapin ang Secret Key
Sa PayMongo dashboard, buksan ang Settings, Product Settings, tapos Developers. Hanapin ang API Keys. Ang Secret Key ay pribadong code para maikonekta ang account.

6. Piliin ang tamang code
sk_test_ ang simula para sa practice. sk_live_ para sa totoong bayad. Kopyahin ang Secret Key na tugma sa gagamitin mo. Huwag ibahagi ang buong code sa iba.

7. Ilagay sa SoleSpace
Bumalik sa Shop Settings. Sa Bayad ng customer (PayMongo), i-paste ang Secret Key. Pindutin ang I-save ang code. Test key lang ang ginagamit sa demo.

8. Naka-save na ang code
Makikita ang mensaheng naka-save na ang PayMongo code. Para sa totoong bayad, kailangan ang live key at mga payment method na pinayagan ng PayMongo. Ang pag-save ng code ay hindi approval ng account.
