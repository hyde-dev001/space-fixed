# Showroom PBR textures

Locally hosted 1K JPEG material maps from Poly Haven, licensed CC0:

- `wood-*`: [Romantic Veneer](https://polyhaven.com/a/romantic_veneer)
- `floor-*`: [Marble 01](https://polyhaven.com/a/marble_01)
- `plaster-*`: [Beige Wall 001](https://polyhaven.com/a/beige_wall_001)

[Poly Haven asset license](https://polyhaven.com/license). Original files downloaded from `https://dl.polyhaven.org/file/ph-assets/Textures/jpg/1k/{asset}/{asset}_{map}_1k.jpg`.

`diff` is sRGB color; `rough` and `nor_gl` are linear roughness/OpenGL normal data. Keep the assets local: the showroom does not depend on a third-party runtime request.
