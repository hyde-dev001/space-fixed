# Shop Owner Phase 5 Owner-Operation Audit Matrix

This is the material-operation inventory for the canonical owner shell and
the remaining local/legacy surface. It complements the [capability retirement
matrix](shop-owner-phase-5-capability-retirement-matrix.md) and the Phase 4
[approval authority matrix](shop-owner-phase-4-approval-matrix.md). A simple
page/tab load is explicitly `N/A_ROUTINE_VIEW`; it is not a material
operation. `Denied-attempt behavior` is part of the contract: a hidden link
is not sufficient.

## Stop checkpoint

No Phase 5 change may promote a `CONDITIONAL`, `OWNER_DENIED`, or
`STOP_FOCUSED_DESIGN` row into an owner operation without a focused design and
an authoritative domain transition. In particular, route/module visibility is
not evidence for POS, uploads, staff/HR actions, audit exports, correction
flows, or protected record access.
